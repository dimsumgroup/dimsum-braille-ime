# 🔍 什麼是點心粵語點字輸入法？

點心粵語點字輸入法（Dimsum Braille IME）是一款專為香港視障人士設計的粵語點字輸入工具，支援 Windows 系統，並與 NVDA 螢幕閱讀器完全相容。
本輸入法採用 Rime（中州韻）引擎，提供高效、準確的粵語點字輸入體驗，適合日常打字、學習及工作。
支援關鍵功能包括：
•
粵語點字輸入（Cantonese Braille Input）
•
無障礙輸入法（Accessibility IME）
•
NVDA / JAWS 螢幕閱讀器支援
•
香港用字與口語詞庫

🌐 官方網站：[https://www.dimsumbrl.work](https://www.dimsumbrl.work)
瀏覽完整功能介紹、最新版本下載、粵語點字教學與無障礙輸入法資源

## 📖 使用指南

歡迎使用「點心粵語點字輸入法」！這是一套專為香港視障朋友度身訂做、在 Windows 系統上完美運作的粵語點字打字工具。

本輸入法採用先進的 Rime (中州韻) 引擎驅動，並完美支援 NVDA 螢幕閱讀器，讓您能用最熟悉的點字邏輯，在電腦上飛快地輸入繁體中文與香港生僻用字。

官方網站：[https://www.dimsumbrl.work/](https://www.dimsumbrl.work/)

### 一、 基本打字指法（並擊輸入）

本輸入法預設採用標準的「六點字」鍵盤排列，請將雙手自然放在鍵盤中間的導盲鍵區域：

* 1. 左手： F (1點)、D (2點)、S (3點)


* 2. 右手： J (4點)、K (5點)、L (6點)



【打字方式】：請「同時按下」對應點位的英文字母鍵，然後「同時放開」（此即為並擊）。例如：若要打出 1、4 點，請同時按下 F 和 J 鍵後放開。

### 二、 選字與上字方式

* 1. 直接上字：按下「空白鍵 (Space)」即可直接送出第一個候選字。為了令使用者打字更快，如果選詞只有一個，會發出音效，使用者可直接按下space上字


* 2. 瀏覽找字：按「下方向鍵」或字母「H」鍵往下瀏覽；按「上方向鍵」或字母「G」鍵往上瀏覽。您也可以按「上翻頁 (Page Up)」與「下翻頁 (Page Down)」鍵進行大範圍翻頁。找到需要的字後，按空白鍵即可上字。


* 3. 快速選字：聽到想要的字時，直接按下鍵盤上方那一排的「實體數字鍵 (1 到 9)」，即可快速送出對應編號的候選字。


* 4. 數字及英文字母輸入建議：如果您要直接輸入純數字，建議直接使用鍵盤上方的實體數字鍵便會自動輸出數字，無須按下 enter 鍵；至於英文字母，可以在Caps Lock為關閉，正在輸入中文的時候用點字鍵盤輸入英文，並按下 Enter 鍵輸出。



### 3、 切換輸入法的方法

為了讓使用者可以快速切換大小寫及輸入法，我們做了一些調整

* 1. 如果Caps Lock處於開的狀態，可以直接用英文鍵盤輸入大寫英文，在小寫狀態則用點字鍵盤輸入中文。


* 2. 使用者可以在不切換任何輸入法的狀態下，按Control+Shift+Space或者Control+Space (視乎Windows在不同視窗下的設定) 把中文輸入切換至英文輸入，或在兩者之間切換，之後就可以用英文鍵盤輸入英文，就算在小寫鍵盤的情況下都可以輸入小寫英文。


* 3. 一般來說，Windows切換不同輸入法的預設按鍵是Windows+Space, 同時我們也建議使用者把點心粵語點字輸入法設定在輸入法列表的第一個，因為開機之後第一次載入字庫需要幾秒鐘時間，如果設定在第一個輸入法，開機時就會立刻載入，當需要使用的時候就不用等待。



### 4、 大幅度改善與本地化的「活字庫」

過往的粵語點字輸入法常有錯字或缺字，為此，我們在「點心」字庫的除錯與本地化工序上投入了大量精力：

* 1. 無縫接軌的「肌肉記憶」和自定詞庫：我們刻意保留了港澳視障朋友慣用的「點寫易」候選字排列次序和使用者自行建立的自定詞庫！老用家無須重新適應，一裝好就能靠原本的肌肉記憶立刻進入高速打字狀態。


* 2. 清除歷史遺留的錯別字與問自本地化：針對以往字庫中長久存在的錯字與繁簡混淆問題，我們特別大規模進行了精準的字元轉換，系統性地清除了大量歷史遺留的錯別字，確保您打出的每一字、每一句都符合標準繁體中文規範。


* 3. 收錄香港口語字與常用日文漢字：完整支援「嘅、嘢、諗、啲、噉、𥄫、𨋢、擸、𡃁、埗、邨、駅」等日常對話、香港地名與地鐵站名用字，社交聊天暢通無阻。


* 4. 符合香港習慣的點字編碼：針對某些粵語特特有發音，我們調整了點字碼對應，讓它更符合香港人用的點寫邏輯。


* 5. 持續維護與進化：開發團隊承諾將持續更新字庫。語言是活的，我們的字庫也會跟著香港人的語言習慣不斷進步。



### 5、 三大模式自由切換 (Control + ` 快速切換)

系統內建三種專屬方案，隨時按下「Control + `」（數字 1 左側的反引號鍵），即可自由切換：

* 1. 點心粵語點字 (標準模式)：候選字順序永遠固定，100% 依賴原有的肌肉記憶。


* 2. 點心粵語點字 (記憶模式)：具備智慧學習功能，會自動記錄您的選字習慣與新詞，常用字會自動排到前面，越打越聰明。


* 3. 點心粵語點字 (一陽指模式)：專為不習慣「六點並擊」的使用者設計。您只需用一根手指依序敲擊鍵盤字母來拼出點字碼，回歸傳統的全盤輸入體驗。
