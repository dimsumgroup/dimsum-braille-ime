點心粵語點字輸入法 1.3.3
Windows 安裝及使用說明

點心係一套畀香港視障朋友用嘅粵語點字輸入法。Windows 版提供 NVDA 附加組件，用嚟報讀候選同查配詞。


安裝點心

1. 開啟安裝檔，按畫面指示安裝。「安裝」確認頁會以唯讀方式顯示點心管理器嘅安裝位置。你可以勾選「建立桌面捷徑」。捷徑叫做「Dimsum Manager - 點心粵語點字輸入法管理器」。
2. 安裝程式會檢查 輸入引擎、處理點心字庫，並將點心加入繁體中文（香港）。已有可用嘅輸入引擎時，會沿用。Windows 要求管理員授權時，按「是」繼續。
3. 如果安裝時 NVDA 正在執行，而你未裝點心附加組件或者仍然用緊舊版，安裝程式會問你想唔想安裝或更新。揀「是」，按「完成」後跟隨 NVDA 指示，再重新啟動 NVDA。
4. 見到「安裝完成」後，按 Windows 鍵加空格，喺繁體中文（香港）下面揀「點心粵語點字輸入法」。
5. 要調整輸入、報讀進階設定或更新詞庫，可以喺按「完成」之前勾選「開啟 Dimsum Manager」。呢個選項預設唔勾選。日後可以用桌面捷徑或開始功能表開啟管理器。

如果偵測到舊版點心，安裝程式會提示你按一下「確定」。新版會保留學習記錄同自訂詞庫，並清理舊版自動更新元件。

如果見到「點心設定尚未完成」，按「完成」會開啟管理器。可以喺「修復與支援」查看原因，再按「繼續設定點心」。


管理器  輸入設定

更改報讀方式、聲線或勾選項會即時套用。

* 自動偵測讀屏軟件。預設開啟。有多款讀屏同時執行時，依次優先用 NVDA、JAWS、Windows 朗讀程式。未偵測到讀屏就關閉候選報讀。
* 候選報讀方式。取消勾選自動偵測，就可以揀「關閉」、「NVDA」、「JAWS」、「Windows 朗讀程式（Narrator）」或「Windows 內置語音合成器」。揀 NVDA 時請安裝點心 NVDA 附加組件。揀 Windows 朗讀程式時請關閉 NVDA 同 JAWS。
* Windows 發音聲線。揀「Windows 內置語音合成器」後可以用 Windows 已安裝嘅聲線，即使冇開讀屏軟件都可以聽候選。有廣東話聲線會預先選用。冇廣東話聲線時，可以自行揀其他已安裝嘅聲線，或者去 Windows 語音設定加裝廣東話。

* 聆聽候選時不報讀數字。勾選後，點心報讀候選時會省略選字數字。一陽指方案可用數字輸入，報讀本身會省略編號。
* 只有一個候選時不播放聲音。提示音預設開啟。當前一段真係得一個候選時會響一下，可以直接按空白鍵上字。即使未裝 NVDA 都可以用。
* 輸入候選不讀配詞解釋。預設會讀配詞。一般報讀讀每個字嘅第一組配詞。用上、下方向鍵或方案指定嘅 G、H 逐個瀏覽時，會讀高亮候選入面每個字嘅全部配詞。
* 將點心設為目前預設輸入法。勾選後，Windows 會將點心設為預設輸入法。
* 單按 Shift 切換中英文。用 Shift 喺點心內切換中文同英文。
* 匯入舊點寫易自訂詞庫。揀原有嘅 cb.dic，管理器會先備份點心現有自訂詞庫，再合併及處理。
* 更新輸入法字庫。有新版先會顯示。按一下會下載並處理輸入法字庫。


管理器  配詞解釋報讀設定

* 在 NVDA 開啟點心配詞解釋。預設關閉。NVDA 桌面配置用數字鍵盤 2，手提配置用 NVDA 鍵加句號。按一下讀檢閱游標所在字，連按兩下讀配詞解釋，連按三下讀 Unicode。勾選後，兩下會讀該字嘅全部點心配詞。關閉後，兩下會用返 NVDA 原有解釋。
* 在 JAWS 開啟點心配詞解釋。預設關閉。按 JAWS 鍵加空格，再按 H 開啟語音紀錄。複製要查嘅一句，再按點心查配詞快捷鍵。
* 在 Windows 朗讀程式（Narrator）開啟點心配詞解釋。預設關閉。按朗讀程式鍵加 Ctrl 加 X，然後按點心查配詞快捷鍵。
* 查配詞快捷鍵（可留空）。按「設定查配詞快捷鍵」，直接按想用嘅鍵。NVDA 可以用呢組鍵直接查最近報讀。JAWS 同 Windows 朗讀程式就先複製要查嘅報讀。單字讀全部配詞，詞語或句子讀每字第一組。可按「清除查配詞快捷鍵」解除綁定。
* 另存配詞表供 NVDA 獨立使用。揀一次資料夾，就會另存 characterDescriptions.dic、symbols.dic 同 cldr.dic。你可以一併備份 NVDA 現用嘅配詞檔。備份放喺所揀位置內嘅「NVDA舊配詞表備份」資料夾。
* 更新報讀配詞表。有新版先會顯示。更新後，NVDA 附加組件會讀取新版配詞。

用 NVDA 時，如果仲未安裝點心附加組件或者仍然用緊舊版，開啟管理器會邀請你安裝或更新。「輸入設定」同「配詞解釋報讀設定」底部亦會顯示「安裝或更新 NVDA 附加組件」。跟隨 NVDA 指示完成安裝，再重新啟動 NVDA。

每次開啟管理器都會檢查 Windows 程式、輸入法字庫同報讀配詞表。有更新會喺同一個視窗列出，可開啟 Windows 程式嘅下載頁，或者直接揀更新字庫或配詞表。按「稍後」後，可以喺「修復與支援」按「查看可用更新」。下次開管理器時，有更新就會再提示。


管理器  修復與支援

* 使用說明。打開呢份說明。開啟官方網站則會開啟點心網站。
* 輸入法設定修復。如果打唔到字、輸入法出現錯誤，或者喺 Windows 輸入法清單搵唔到點心，可以按「輸入法設定修復」。管理器會檢查引擎、重新處理字庫，再核對 Windows 輸入法登記。
* 點心輸入法語言。安裝會用繁體中文（香港）。如果呢部電腦曾成功用另一個語言加入點心，先可以喺清單揀嗰個語言，再按「套用輸入法語言」。
* 檢查程式更新。檢查有冇新版 Windows 安裝程式。
* 查看操作記錄及版本。可以用鍵盤查看或複製記錄。有問題時，可以用「另存問題回報」儲存版本、設定同最近操作記錄，以便回報。
* 移除點心粵語點字輸入法。管理器、點心輸入法、輸入引擎同點心 NVDA 附加組件會一併移除。學習記錄同自訂詞庫會保留。如有需要，按提示重啟 NVDA 或 Windows。


點字輸入指法及用法

一、 基本打字指法（並擊輸入）

本輸入法預設採用標準的「六點字」鍵盤排列，請將雙手自然放在鍵盤中間的導盲鍵區域：

* 左手：F (1點)、D (2點)、S (3點)
* 右手：J (4點)、K (5點)、L (6點)

【打字方式】：請「同時按下」對應點位的英文字母鍵，然後「同時放開」（此即為並擊）。例如：若要打出 1、4 點，請同時按下 F 和 J 鍵後放開。

二、 選字與上字方式

* 直接上字：按下「空白鍵 (Space)」即可送出目前選中嘅候選字。如果只有一個候選，預設會響一下。
* 瀏覽找字：按「下方向鍵」或字母「H」鍵往下瀏覽；按「上方向鍵」或字母「G」鍵往上瀏覽。您也可以按「上翻頁 (Page Up)」與「下翻頁 (Page Down)」鍵進行大範圍翻頁。找到需要的字後，按空白鍵即可上字。
* 快速選字：聽到想要的字時，直接按下鍵盤上方那一排的「實體數字鍵 (1 到 9)」，即可快速送出對應編號的候選字。
* 數字及英文字母輸入建議：如果您要直接輸入純數字，建議直接使用鍵盤上方的實體數字鍵便會自動輸出數字，無須按下 enter 鍵； 至於英文字母，可以在Caps Lock為關閉，正在輸入中文的時候用點字鍵盤輸入英文，並按下 Enter 鍵輸出。

三、 切換輸入法的方法

為了讓使用者可以快速切換大小寫及輸入法，我們做了一些調整：

* 如果Caps Lock處於開的狀態，可以直接用英文鍵盤輸入大寫英文，在小寫狀態則用點字鍵盤輸入中文。
* 使用者可以在不切換任何輸入法的狀態下，按Control+Shift+Space或者Control+Space (視乎Windows在不同視窗下的設定) 把中文輸入切換至英文輸入，或在兩者之間切換，之後就可以用英文鍵盤輸入英文，就算在小寫鍵盤的情況下都可以輸入小寫英文。
* 一般來說，Windows切換不同輸入法的預設按鍵是Windows+Space, 同時我們也建議使用者把點心粵語點字輸入法設定在輸入法列表的第一個，因為開機之後第一次載入字庫需要幾秒鐘時間，如果設定在第一個輸入法，開機時就會立刻載入，當需要使用的時候就不用等待。

四、 大幅度改善與本地化的「活字庫」

過往的粵語點字輸入法常有錯字或缺字，為此，我們在「點心」字庫的除錯與本地化工作上投入了大量精力：

* 無縫接軌的「肌肉記憶」：我們刻意保留了港澳視障朋友慣用的「點寫易」候選字排列次序！老用家無須重新適應，一裝好就能靠原本的肌肉記憶立刻進入高速打字狀態。
* 修正舊字庫字詞同調整本地用字：針對以往字庫中長久存在的錯字與繁簡混淆問題，我們特別大規模進行了精準的字元轉換，系統性地清除了大量歷史遺留的錯別字，確保您打出的每一字、每一句都符合標準繁體中文規範。
* 收錄香港口語字與常用日文漢字：完整支援「嘅、嘢、諗、啲、噉、𥄫、𨋢、擸、𡃁、埗、邨、駅」等日常對話、香港地名與地鐵站名用字，社交聊天暢通無阻。
* 符合香港習慣的點字編碼：針對某些粵語特有發音，我們調整了點字碼對應，讓它更符合香港人用的點寫邏輯。
* 持續維護與進化：開發團隊承諾將持續更新字庫。語言是活的，我們的字庫也會跟著香港人的語言習慣不斷進步。

五、 切換三種輸入方案

系統內建三種專屬方案，隨時按下「Control + `」（數字 1 左側嘅反引號鍵），即可自由切換：

* 點心粵語點字（標準版）：【預設】候選字順序永遠固定，100% 依賴原有的盲打記憶。
* 點心粵語點字（記憶版）：具備智慧學習功能，會自動記錄您的選字習慣與新詞，常用字會自動排到前面，越打越聰明。
* 點心粵語點字（一陽指）：專為不習慣「六點並擊」的使用者設計。您只需用一根手指依序敲擊鍵盤字母來拼出點字碼，回歸傳統的全盤輸入體驗。

六、 給「點寫易」老用戶的溫馨提示

* 遇到整串字變成英文代碼（空碼）怎麼辦？
若因打錯字或多按標點導致畫面出現英文代碼，「千萬不要全部刪掉」！只需按一次 Backspace (退格鍵) 刪除最後一個錯誤符號，前面的中文字就會瞬間全部回來。
* 如何把黏在一起的字拆開？
若系統組錯詞，可按 Backspace 刪除後面的字並先上前面的字；或者在兩個字的代碼中間手動插入一個單引號 (')，系統就會強制將其切開。
* 關於英文字母 G 與 H 的輸出限制：
基於系統翻頁快捷鍵的保護機制，在Caps Lock為關閉並且在中文模式，按下 Enter 送出用點字鍵盤輸入的英文原碼時，g 與 h 必定會以大寫 G 與 H 輸出。

七、 跟傳統「點寫易」有什麼不同與自訂功能？

* 支援「長句連打」：點心擁有強大的「自動組句」功能，您可以一口氣打完一長串點字碼，系統會自動尋找最適合的詞語組合。
* 極高自由度的客製化：點心輸入法的設定為純文字檔，任何人都可以輕鬆開啟字典新增專屬字彙，不再受限於軟體開發者的更新頻率。
* 舊用戶無縫過渡：過往「點寫易」的老用戶會在 C:\Users\Public\Documents 建立一個名為 cb.dic 的自訂詞庫檔案，你可以在管理器匯入呢個詞庫。
* 全新建立與使用：如果本來沒有使用此功能的使用者，現在也可以自行建立 cb.dic 檔案然後匯入，這樣你就無需打開系統檔案。
* 舊點寫易詞庫編碼格式：檔案內的編碼格式為「字根[Tab]文字」。如果同一個字根有多個候選詞選項，可以使用「[Tab]」鍵將其分隔開。
例如：h3k;aj$'	香港人	香江人（這代表輸入該字根時，系統會同時提供「香港人」與「香江人」兩個選項供您選擇）。
