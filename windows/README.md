# 點心粵語點字輸入法管理器 1.3.1

用家說明見 [安裝及使用說明_Win.txt](安裝及使用說明_Win.txt)。安裝器會內附呢份 TXT。管理器「修復與支援」嘅「使用說明」會開啟原檔。

## 安裝同資料

- 互動安裝可選擇建立「Dimsum Manager - 點心粵語點字輸入法管理器」桌面捷徑。安裝器會檢查或安裝引擎、處理字庫、核對繁體中文（香港）喺 Windows 語言清單同 TSF 都已啟用，再完成安裝。完成頁嘅「開啟 Dimsum Manager」預設唔勾選。設定失敗時按「完成」會打開管理器嘅「修復與支援」。
- 語言管理只提供呢部電腦曾驗證成功嘅選擇。切換輸入語言會先核對所選項目已啟用，先移除其他點心項目。已有獨立引擎會沿用。管理器會隱藏已核對嘅引擎安裝項目。
- 每次開啟管理器都會檢查 Windows 程式、輸入法字庫同報讀配詞表。有新版嘅項目會喺同一個更新視窗顯示。按「稍後」可喺「修復與支援」再查看，下次開管理器仍有更新會再提示。資料更新比較 GitHub 主分支各檔案嘅 Git blob ID。處理 Rime 失敗時保留上次成功嘅字庫。配詞三個檔案驗證完成後先更換指標。
- Windows 程式更新檢查正式 GitHub Release 嘅標籤及同版本 Dimsum_Setup_v版本.exe 附件。開啟下載頁由用家自行下載及安裝。
- 用家設定及下載資料喺 %LOCALAPPDATA%\DimsumInput。Rime 用家資料預設喺 %APPDATA%\Rime，尊重已設定嘅 RimeUserDir。管理器支援另存版本、設定同最近操作記錄畀用家回報。
- 由舊版 1.1.x 升級時，顯示一次「確定」提示，停用同等待已核對嘅舊更新程式，更新引擎並處理點心。確認 Windows 已啟用後會清理舊更新檔、登入項目同安裝登記。遷移記錄可供中斷後重試，Rime 學習記錄同自訂詞庫原位保留。
- 管理器同 Windows「已安裝的應用程式」都會移除點心、引擎同已辨認嘅 NVDA 附加組件。保留用家自訂詞庫同學習記錄。避免執行舊版 1.1.x 解除安裝程式，舊版會刪除 Rime 用家資料。

## NVDA 同提示音

- 互動安裝完成前，如果 NVDA 正在執行而且目前設定未有點心附加組件，安裝器會邀請安裝。用家接受後，按「完成」會開啟 NVDA 附加組件安裝。平時開啟管理器仍會檢查同邀請安裝。「輸入設定」同「配詞解釋報讀設定」兩頁會顯示相同安裝入口。
- 候選自動讀選字數字同每個字嘅第一組配詞。逐個瀏覽時讀高亮候選中每個字嘅全部配詞。可以獨立關閉數字同配詞。三個 Rime 輸入方案各自保留按鍵定義。
- 提示音程序喺登入時自動啟動。真係只有一個候選時會播放內附 WAV。呢個功能同 NVDA 附加組件無關。
- NVDA 檢閱當前字元第二下嘅覆寫預設關閉。查最近報讀嘅自訂快捷鍵獨立生效，可錄製或清除。文字喺記憶體暫存，查詢回覆會保留原句。
- 可以另存三份配詞檔，並將 NVDA 現用字典另作備份。附加組件直接讀管理器已下載或內附資料。

## 建置

將 `windows` 目錄放喺 [dimsum-braille-ime](https://github.com/dimsumgroup/dimsum-braille-ime) 根目錄，再喺 Windows 用 .NET 8 SDK、Python 3 同 Inno Setup 6.6 或以上建置。

```powershell
cd windows
.\build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

如資料喺另一個 checkout，可以用 `-RimeSource` 指定。省略 `-InnoCompiler` 會只產生 `dist\manager`。建置要有 7-Zip 及 NSIS 3.11，可用 `-SevenZip` 同 `-NsisCompiler` 指定路徑。用 `-EngineInstaller` 指定 0.17.4.0 原廠安裝檔，建置會核對 SHA-256，提取原廠二進位檔並重封裝。正式發行可傳入 `-SigningThumbprint` 同 Windows SDK 嘅 `-SignTool`，簽署及驗證內附引擎安裝器、管理器同外層安裝檔。預覽包使用公開倉庫 `36e2adec6eda3513fab0aa7f4afd6f42e354ced3` 嘅方案、字庫及配詞。提示音使用本次提供嘅 WAV。

## 驗收

- 編譯管理器同安裝器，再核對 EXE 內附說明、引擎同 NVDA 附加組件。用 tests/reporting.py .. 測 NVDA 報讀邏輯。用 tests/reporting.lua 測來自 Rime 嘅事件。
- 在只用英文嘅 Windows 同已用繁體中文（香港）嘅 Windows 分別全新安裝，檢查 Win+Space、完成頁勾選同桌面捷徑。取消管理員授權，確認能由「繼續設定點心」重試。
- 按「輸入法設定修復」，核對提示字句同重新檢查引擎、處理字庫、登記輸入法嘅流程。
- 升級 1.1.x，檢查一次提示、學習同自訂詞庫保留、舊程式同登入項目移除。再使用統一移除入口，核對引擎及附加組件都已移除。
- 用有安裝及無安裝點心附加組件嘅 NVDA 測試安裝器同管理器邀請。試接受、拒絕、完成後保持管理器關閉同勾選開啟管理器，核對同一次安裝只邀請一次。逐項更改設定，試錄製、清除、重啟 NVDA 同按鍵讀出各項說明。
- 測 f$ → f$1 首候選相同、用方向鍵同 G／H 瀏覽、記憶版重排同「不過你」轉段。核對音效只會喺當前段落真係得一個候選時播放。
- 測試程式、字庫、配詞表各自及同時有更新。核對同一個對話框只顯示可用項目，按「稍後」再重開管理器會再次提示。測一份更新失敗時另一份仍可處理，以及重開管理器後嘅狀態。從管理器開啟 TXT，並檢查另存回報內容。
