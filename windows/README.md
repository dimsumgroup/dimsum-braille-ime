# 點心粵語點字管理器 Windows 測試版 1.3.1

## 安裝及試用

打開 `Dimsum_Setup_v1.3.1.exe`。安裝時可以選擇建立桌面捷徑。按「完成」會即時開啟點心粵語點字輸入法管理器。管理器嘅數字係首次設定次序。

1. **01 安裝 Rime 輸入引擎（未安裝時）**。電腦已有可用嘅輸入引擎就可以跳過。安裝包已內附精簡引擎，離線都可安裝。部署後方案選單有標準版、記憶版同一陽指三個點心方案，沿用用家已安裝嘅其他方案設定。
2. **02 設定並部署點心**。管理器喺首次開啟時記低目前用家嘅輸入語言，將「點心粵語點字輸入法」加入對應語言。支援嘗試繁中香港、繁中台灣及英文輸入語言，如果 Windows 拒絕加入到目前語言，會嘗試繁中香港。想一開始就用點心，可先勾選「將點心設為目前預設輸入法」。

單按 Shift 係點心啟用後嘅中英文切換，可喺「打字設定」關閉。原有自訂 Shift 綁定會保留。

完成部署後會即時啟動提示音背景程序，之後每次登入都會啟動。已有自訂引擎提示音嘅用家可以關閉點心嘅聲音播放，避免響兩次。提示音用提供嘅 WAV，Rime 探測到一個輸入段落真係得一個候選時會通知背景程序播放。已開啟提示音嘅情況下，即使冇安裝 NVDA 都可以用。點心報讀附加元件 1.3.1 已交由同一個播放程序負責提示音。

安裝器複製檔案後，如果 NVDA 正在執行而目前用家設定需要安裝或更新附加元件，安裝器會顯示邀請。亦可使用管理器嘅「安裝 NVDA 附加元件（NVDA使用者專用）」按鈕，完成安裝後重啟 NVDA。新用家預設用「標準報讀模式」，升級會保留已儲存嘅選擇。「標準」會讀一般候選同選字編號，「精簡」會讀候選並省略編號。「補讀模式」會保留 NVDA 一般候選報讀，在例如 `f$1` 高亮字相同時補讀。一陽指輸入方案用數字輸入，標準報讀會省略選字編號。候選用配詞報讀時，自動讀每個字嘅第一組。用方向鍵或方案定義嘅 G／H 逐個瀏覽，補讀、標準同精簡模式會讀新高亮候選中每個字嘅全部配詞。

### 字庫與配詞更新

- 開啟管理器會檢查 GitHub 上字庫同配詞嘅檔案內容，喺「操作結果/版本」分開顯示有冇新版。要套用時，撳對應嘅更新按鈕。
- 按「更新及部署 Rime 字庫」會檢查、下載同部署。之前下載咗嘅字庫可以用「重新部署或套用已下載字庫」處理。
- 按「更新點心報讀配詞」會更新三份資料。附加元件會使用已下載或內附配詞。
- 「另存配詞表供 NVDA 獨立使用」會將 `characterDescriptions.dic`、`symbols.dic` 同 `cldr.dic` 另存到同一個資料夾。需要備份可以喺對話框揀「是」。管理器會將找到嘅 NVDA 原有檔案按語言放入 `NVDA舊配詞表備份`，並顯示搵唔到嘅檔案。
- 由前一個測試版升級時，附加元件會備份並移走用家符號字典入面仍有點心標記嘅合併項目。備份存入 `DimsumPronunciations\symbol-migration-backups`。
- 重新部署會將三個點心方案嘅候選放入 Windows 組字文字，供 NVDA 原生組字報讀讀取。可以分別測試關閉點心候選報讀，同卸載點心附加元件後嘅行為。
- 程式更新會按版本號檢查有正式 Windows 安裝附件嘅 GitHub 發行版，由用家確認後開啟下載頁。

### NVDA 查配詞

管理器嘅「使用點心字詞解釋」預設開啟。桌面配置用數字鍵盤 `2`，手提電腦配置用 `NVDA+句號`。一下讀檢閱游標所在字，兩下讀解釋，三下讀 Unicode。開啟點心字詞解釋時，兩下會讀該字嘅全部點心配詞。關閉或字表冇該字時，兩下會用返 NVDA 原有解釋。

「查最近報讀配詞快捷鍵（可留空）」獨立生效。撳「按下查配詞快捷鍵」，再按例如 `Ctrl+Alt+D`，之後撳「儲存報讀設定」。用自訂快捷鍵之前可以用 NVDA 原生快捷鍵聽解釋，再對照點心讀法。清除快捷鍵並儲存即可解除綁定。附加元件將最近報讀暫存喺記憶體，查詢回覆唔會取代原句。Rime 只會喺啟用候選報讀時寫出最近一份候選快照，內容有候選文字、選字標籤及高亮位置。

### 升級與回復

- 直接安裝新版。舊用家按「完成」開啟管理器時，如有已辨認嘅舊版元件，會見到一次遷移確認。用家資料預設路徑係 `%APPDATA%\Rime`。
- 舊版 1.1.x 同管理器各自有安裝登記。遷移成功後會移除已辨認嘅舊版登記，程式列表會保留管理器。
- 按「確定」後，管理器會停用已核對嘅舊版更新、備份用家資料，安裝內附引擎並重新部署點心。遷移將已安裝 NVDA 嘅現存中文配詞檔按語言備份到 `%LOCALAPPDATA%\DimsumInput\舊版遷移備份\<遷移編號>\NVDA舊配詞表備份`。部署成功後，先清理舊更新程式、核對過嘅排程同舊登記。Windows 可能要求管理員授權。步驟 01 安裝好引擎後會立即隱藏引擎登記。
- 管理器可以揀「只移除點心，保留輸入引擎」或「一併移除點心及輸入引擎」。兩個選項會保留 Rime 學習記錄同自訂詞庫。使用 Windows「已安裝的應用程式」移除管理器時，會保留輸入引擎。**請避免執行舊版 1.1.x 解除安裝程式**，佢會刪除 Rime 用家資料。
- 兩種移除方式都會移除已辨認嘅點心 NVDA 附加元件，包括待安裝版本。如 NVDA 正在執行，重啟 NVDA 後會卸載已載入嘅附加元件。
- 遷移會等現時登入階段嘅舊引擎退出。中斷時會顯示失敗步驟同備份位置。按步驟 02 可以由已儲存階段繼續。引擎二進位檔同安裝登記會備份供回復用。
- 一併移除引擎時，管理器會等候原廠引擎完成移除，再核對輸入服務、登入項目、安裝登記同檔案。等待重新啟動清除嘅檔案會有獨立提示。
- 如果引擎檔案同安裝登記已移除，管理器可以清理只指向已不存在系統 DLL 嘅已知輸入服務登記。
- 遷移完成或移除點心時，會備份再移走已辨認嘅舊更新程式同舊 Inno Setup 解除安裝檔案。舊程式資料夾清空後會移除。
- 移除點心時如有未完成嘅部署，管理器會喺 `%LOCALAPPDATA%\DimsumInput\未完成部署備份` 保留部署記錄同原有檔案，同時保留現有字庫同自訂詞庫。
- 更新管理器時，安裝程式會請舊管理器正常關閉，暫停提示音程序，等執行檔可以寫入後先換檔。如果管理器仲喺度完成操作，請等操作完成再按「安裝」。
- 匯入 `cb.dic` 會合併到 `dimsum_cb.user.dict.yaml`，保留原有詞條及權重，備份喺 `%LOCALAPPDATA%\DimsumInput\backups`。
- 部署會核對編譯字庫，失敗後會回復部署前嘅來源檔並再部署。現有輸入方案同可辨認嘅自訂設定會保留。

## 建置

將 `windows` 目錄放喺 [dimsum-braille-ime](https://github.com/dimsumgroup/dimsum-braille-ime) 根目錄，再喺 Windows 用 .NET 8 SDK、Python 3 同 Inno Setup 6.6 或以上建置。

```powershell
cd windows
.\build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

如資料喺另一個 checkout，可以用 `-RimeSource` 指定。省略 `-InnoCompiler` 會只產生 `dist\manager`。建置要有 7-Zip 及 NSIS 3.11，可用 `-SevenZip` 同 `-NsisCompiler` 指定路徑。用 `-EngineInstaller` 指定 0.17.4.0 原廠安裝檔，建置會核對 SHA-256，提取原廠二進位檔並重封裝。正式發行可傳入 `-SigningThumbprint` 同 Windows SDK 嘅 `-SignTool`，簽署及驗證內附引擎安裝器、管理器同外層安裝檔。預覽包使用公開倉庫 `36e2adec6eda3513fab0aa7f4afd6f42e354ced3` 嘅方案、字庫及配詞。提示音使用本次提供嘅 WAV。

## 驗收

### 已做嘅開發驗證

- Windows x64 管理器交叉編譯。
- 用 Linux 上嘅 librime 實際部署三套方案，核對編譯字庫嘅 CRC 同 Lua 設定。亦用內附字庫喺三套方案重現 `f$` 補聲調嘅情境，確認高亮仍然係「分」、第二個候選由「芬」變成「份」時，Lua 會發出聲調事件。
- 模擬 Rime 事件驗證補聲調、去重、候選跨頁、記憶版排序及「不過你」轉段。用 Linux librime 在三個方案實測方向鍵，在標準版同記憶版實測 G／H。
- 核對 `日本` 首組及 `過` 全部配詞、舊詞庫匯入去重、Rime CRC 算法同 Windows 發行附件篩選。

### Windows／NVDA 實機

1. 打 `f$`，再補聲調成 `f$1`。高亮候選仍然係「分」，應補讀一次，即使後面嘅候選有變。另一組輸入要驗證高亮候選有變時由 NVDA 照常讀。亦要測試快速連續鍵入，核對冇重複。
2. 揀「標準」，淨打 `f$`，聽候選編號同讀法。完成當前輸入，再揀「精簡」重試同一輸入，確認會讀候選但唔讀編號。切返「補讀」或「關閉」，確認恢復 NVDA 原有讀法。
3. 記憶版反覆選同一候選，確認重排後聽到嘅編號同按鍵結果一致。輸入「不過你」並按數字選「不過」，下一段候選應立即報讀。
4. 逐個瀏覽「日本」時核對全組配詞。首頁真正得一個候選會響提示音，多頁最後一項冇單候選提示音。
5. 用有自訂詞庫同學習記錄嘅舊版升級。試驗壞字庫及中斷部署，確認回復結果。卸載新版，確認舊詞庫、學習記錄及特意清空嘅快捷鍵保留。
6. 用桌面及手提嘅 NVDA 按鍵配置，測試同一字按一下、兩下同三下。關閉「使用點心字詞解釋」及候選報讀後再測，並用自訂快捷鍵對照點心配詞。查單字、詞語及整句各一次，重按確認仍用原句。
7. 實測 NVDA 原有方案選單報讀。JAWS 候選報讀同最近報讀查詞，暫未接入。上屏朗讀同整行朗讀暫未接入。
8. 記錄防毒實際攔截嘅檔名、產品、偵測名稱同時間，再用已簽署正式包比對。


### 1.3.1 舊版遷移及移除驗收

- 喺英文、繁中台灣及繁中香港嘅乾淨 Windows，用離線安裝檔完成 01、02，確認輸入法清單顯示「點心粵語點字輸入法」。另試保留及設為預設兩種設定。
- 喺已裝 1.1.x 嘅帳戶升級，按安裝完成只見一次遷移提示。確認後檢查清單只顯示一個點心，舊更新檔、啟動項目同匹配嘅排程已清理，學習記錄、自訂配詞同資料仍可用。重試拒絕授權同中斷遷移兩個情境。乾淨安裝及已有獨立引擎時，確認管理器直接開啟。
- 用有完整及部分中文配詞檔嘅 NVDA 試舊版遷移，核對備份同安裝目錄原檔一致，並確認 NVDA 未安裝時仍可遷移。
- 分別驗證引擎移除成功、需要重啟、尚有項目未移除三種結果。核對 Rime 用家資料保留。
- 試單按 Shift、Shift 組合鍵、輸入未完成時切換同切返中文。開啟同關閉 NVDA 各試一次提示音，再試候選分頁到最後一項同撳空格上屏。
- 測試更新及部署 Rime 字庫、手動更新配詞、另存連同或略過備份，以及資料夾有同名配詞檔、NVDA 未安裝同找不到部分現用檔案嘅情況。
- 管理器開啟時分別測試字庫最新、配詞最新、其中一份有更新、Rime 下載後尚待部署同離線。確認 NVDA 收到有新版提示，選取焦點仍然留喺原位。
- 喺 NVDA 開啟時，試用「按下查配詞快捷鍵」錄製 `Ctrl+Alt+D`，確認尚未儲存時仍沿用原設定，儲存後可以查配詞。再試 Esc 取消、數字鍵、功能鍵及「清除查配詞快捷鍵」後儲存。

- 用 `Tab` 跳到兩個查配詞控制項，核對名稱、狀態或設定值同相應說明，以及每段說明有冇重複。
