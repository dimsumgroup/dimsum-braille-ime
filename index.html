點心粵語點字輸入法

「點字書寫我心」

專為視障人士與粵語點字使用者度身訂做的輸入工具。支援 Windows、macOS 與行動裝置，讓點字輸入變得前所未有地流暢。

  • 其他：改善引擎底層架構，單字發出聲音反應更快。更新最新字庫。

📥 安裝指南

  1. 1
    下載安裝程式：點擊上方「下載最新版本 (v0.5.1)」按鈕，或前往 GitHub Releases 頁面 取得最新版本。
  2. 2
    執行安裝程式：雙擊下載好的 Dimsum_Setup_v0.5.1.exe 檔案，以系統管理員身份執行。
  3. 3
    完成安裝精靈：按照安裝精靈的指示逐步完成安裝，全程約需 1–2 分鐘，無需網路連線。
  4. 4
    切換輸入法：安裝完成後，按下 Windows 鍵 + 空白鍵 切換至點心輸入法。
  5. 5
    確認啟動：當您聽到 NVDA 報讀「點心粵語點字」時，即代表已成功切換，可以開始打字！

點心粵語點字輸入法 - 使用指南

歡迎使用「點心粵語點字輸入法」！這是一套專為香港視障朋友度身訂做、在 Windows 系統上完美運作的粵語點字打字工具。[cite: 1]

本輸入法採用先進的 Rime (中州韻) 引擎驅動，並完美支援 NVDA 螢幕閱讀器，讓您能用最熟悉的點字邏輯，在電腦上飛快地輸入繁體中文與香港生僻用字。[cite: 1]

一、 基本打字指法（並擊輸入）

本輸入法預設採用標準的「六點字」鍵盤排列，請將雙手自然放在鍵盤中間的導盲鍵區域：[cite: 1]

  • 左手： F (1點)、D (2點)、S (3點) [cite: 1]
  • 右手： J (4點)、K (5點)、L (6點) [cite: 1]

【打字方式】：請「同時按下」對應點位的英文字母鍵，然後「同時放開」（此即為並擊）。例如：若要打出 1、4 點，請同時按下 F 和 J 鍵後放開。[cite: 1]

二、 選字與上字方式

  • 直接上字：按下「空白鍵 (Space)」即可直接送出第一個候選字。[cite: 1] 為了令使用者打字更快，如果選詞只有一個，會發出音效，使用者可直接按下space上字 [cite: 1]
  • 瀏覽找字：按「下方向鍵」或字母「H」鍵往下瀏覽；按「上方向鍵」或字母「G」鍵往上瀏覽。您也可以按「上翻頁 (Page Up)」與「下翻頁 (Page Down)」鍵進行大範圍翻頁。找到需要的字後，按空白鍵即可上字。[cite: 1]
  • 快速選字：聽到想要的字時，直接按下鍵盤上方那一排的「實體數字鍵 (1 到 9)」，即可快速送出對應編號的候選字。[cite: 1]
  • 數字及英文字母輸入建議：如果您要直接輸入純數字，建議直接使用鍵盤上方的實體數字鍵便會自動輸出數字，無須按下 enter 鍵； 至於英文字母，可以在Caps Lock為關閉，正在輸入中文的時候用點字鍵盤輸入英文，並按下 Enter 鍵輸出。[cite: 1]

三、 切換輸入法的方法

為了讓使用者可以快速切換大小寫及輸入法，我們做了一些調整 [cite: 1]

  • 如果Caps Lock處於開的狀態，可以直接用英文鍵盤輸入大寫英文，在小寫狀態則用點字鍵盤輸入中文。[cite: 1]
  • 使用者可以在不切換任何輸入法的狀態下，按Control+Shift+Space或者Control+Space (視乎Windows在不同視窗下的設定) 把中文輸入切換至英文輸入，或在兩者之間切換，之後就可以用英文鍵盤輸入英文，就算在小寫鍵盤的情況下都可以輸入小寫英文。[cite: 1]
  • 一般來說，Windows切換不同輸入法的預設按鍵是Windows+Space, 同時我們也建議使用者把點心粵語點字輸入法設定在輸入法列表的第一個，因為開機之後第一次載入字庫需要幾秒鐘時間，如果設定在第一個輸入法，開機時就會立刻載入，當需要使用的時候就不用等待。[cite: 1]

四、 大幅度改善與本地化的「活字庫」

過往的粵語點字輸入法常有錯字或缺字，為此，我們在「點心」字庫的除錯與本地化工序上投入了大量精力：[cite: 1]

  • 無縫接軌的「肌肉記憶」：我們刻意保留了港澳視障朋友慣用的「點寫易」候選字排列次序！老用家無須重新適應，一裝好就能靠原本的肌肉記憶立刻進入高速打字狀態。[cite: 1]
  • 清除歷史遺留的錯別字與問自本地化：針對以往字庫中長久存在的錯字與繁簡混淆問題，我們特別大規模進行了精準的字元轉換，系統性地清除了大量歷史遺留的錯別字，確保您打出的每一字、每一句都符合標準繁體中文規範。[cite: 1]
  • 收錄香港口語字與常用日文漢字：完整支援「嘅、嘢、諗、啲、噉、𥄫、𨋢、擸、𡃁、埗、邨、駅」等日常對話、香港地名與地鐵站名用字，社交聊天暢通無阻。[cite: 1]
  • 符合香港習慣的點字編碼：針對某些粵語特有發音，我們調整了點字碼對應，讓它更符合香港人用的點寫邏輯。[cite: 1]
  • 持續維護與進化：開發團隊承諾將持續更新字庫。語言是活的，我們的字庫也會跟著香港人的語言習慣不斷進步。[cite: 1]

五、 三大模式自由切換 (Control + ` 快速切換)

系統內建三種專屬方案，隨時按下「Control + `」（數字 1 左側的反引號鍵），即可自由切換：[cite: 1]

  • 點心粵語點字 (記憶模式)：【預設推薦】具備智慧學習功能，會自動記錄您的選字習慣與新詞，常用字會自動排到前面，越打越聰明。[cite: 1]
  • 點心粵語點字 (標準模式)：關閉記憶功能，候選字順序永遠固定。適合需要嚴格測試、校對字庫的使用者，100% 依賴原有的盲打記憶。[cite: 1]
  • 點心粵語點字 (一陽指模式)：專為不習慣「六點並擊」的使用者設計。您只需用一根手指依序敲擊鍵盤字母來拼出點字碼，回歸傳統的全盤輸入體驗。[cite: 1]

六、 給「點寫易」老用戶的溫馨提示

  • 遇到整串字變成英文代碼（空碼）怎麼辦？
    若因打錯字或多按標點導致畫面出現英文代碼，「千萬不要全部刪掉」！只需按一次 Backspace (退格鍵) 刪除最後一個錯誤符號，前面的中文字就會瞬間全部回來。[cite: 1]
  • 如何把黏在一起的字拆開？
    若系統組錯詞，可按 Backspace 刪除後面的字並先上前面的字；或者在兩個字的代碼中間手手動插入一個單引號 (')，系統就會強制將其切開。[cite: 1]
  • 關於英文字母 G 與 H 的輸出限制：
    基於系統翻頁快捷鍵的保護機制，在Caps Lock為關閉並且在中文模式，按下 Enter 送出用點字鍵盤輸入的英文原碼時，g 與 h 必定會以大寫 G 與 H [cite: 1] 輸出。[cite: 2]

七、 跟傳統「點寫易」有什麼不同？

  • 完美支援最新環境：點心輸入法完美相容 Windows 10/11 及最新版 NVDA，保證不再有無法安裝的問題。[cite: 2]
  • 支援「長句連打」：點心擁有強大的「自動組句」功能，您可以一口氣打完一長串點字碼，系統會自動尋找最適合的詞語組合。[cite: 2]
  • 極高自由度的客製化：點心輸入法的設定為純文字檔，任何人都可以輕鬆開啟字典新增專屬字彙，不再受限於軟體開發者的更新頻率。[cite: 2]
