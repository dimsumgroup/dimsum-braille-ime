  1. 1
    下載安裝程式：點擊上方「下載最新版本 (v0.7.1)」按鈕，或前往 GitHub Releases 頁面 取得最新版本。
  2. 2
    執行安裝程式：雙擊下載好的 Dimsum_Setup_v0.7.1.exe 檔案，以系統管理員身份執行。
  3. 3
    完成安裝精靈：按照安裝精靈的指示逐步完成安裝，全程約需 1–2 分鐘，安裝時會自動偵測最新版本及字庫。
  4. 4
    切換輸入法：安裝完成後，按下 Windows 鍵 + 空白鍵 切換至點心輸入法。
  5. 5
    確認啟動：當您聽到 NVDA 報讀「點心粵語點字」時，即代表已成功切換，可以開始打字！

點心粵語點字輸入法 - 使用指南

歡迎各位使用「點心粵語點字輸入法」！本軟體是專門為香港視障朋友們度身打造，並能夠在 Windows 作業系統上順暢運作的粵語點字打字利器。

此輸入法由先進的 Rime（中州韻）引擎提供動力，同時全面支援 NVDA 螢幕報讀軟體，使您可以使用習慣的點字邏輯，於電腦上迅速輸入繁體中文及香港本地罕用字。

一、 基礎打字指法（並擊輸入）

輸入法預設使用標準「六點字」鍵盤配置，請把雙手自然放置於鍵盤中央的導盲鍵區：

  • 左手負責： F（1點）、D（2點）、S（3點）
  • 右手負責： J（4點）、K（5點）、L（6點）

【打字方法】：請「同時按住」對應點數的英文字母鍵，接著「同時鬆開」（這就是並擊）。舉例來說：如果想輸入 1、4 點，請同時按住 F 與 J 鍵再放開。

二、 選字與上字方式

  • 直接上字：按「空白鍵 (Space)」就能直接輸出首個候選字。為提升打字速度，若候選詞僅有一個，系統會發出提示音，此時可直接按 Space 輸出。
  • 瀏覽找字：使用「下方向鍵」或「H」鍵向下瀏覽；使用「上方向鍵」或「G」鍵向上尋找。也可利用「Page Up」和「Page Down」進行大範圍翻頁。找到目標字後按空白鍵輸出。
  • 快速選字：聽見所需字詞時，直接敲擊鍵盤上排的「實體數字鍵 1-9」，就能迅速輸出對應編號的字。
  • 數字與英文輸入建議：若需直接打出純數字，建議直接按鍵盤上排的數字鍵即可自動輸出，不須按 Enter；輸入英文時，可在 Caps Lock 關閉的中文輸入狀態下，用點字鍵盤打出英文碼，再按 Enter 鍵送出。

三、 切換輸入法的方法

為了方便用戶快速切換大小寫與輸入模式，我們進行了以下優化：

  • 當 Caps Lock 開啟時，可直接用英文鍵盤輸入大寫字母；若處於小寫狀態，則預設以點字鍵盤輸入中文。
  • 用戶可以在不切換系統輸入法的情況下，按下 Control+Shift+Space 或 Control+Space（根據不同的 Windows 視窗設定），將中文模式切換為英文模式，或者在兩者間互切。切換後便能以英文鍵盤輸入英文，即使在小寫狀態亦可輸入小寫字母。
  • 通常 Windows 預設切換輸入法的快捷鍵是 Windows+Space。我們強烈建議將點心粵語點字輸入法排在系統輸入法列表的首位。因為開機首次載入字庫需時數秒，設定在首位可讓系統於開機時自動載入，真正需要打字時就無需等待。

四、 大幅度改善與本地化的「活字庫」

以往的粵語點字輸入法經常出現錯字或缺字，因此我們在「點心」字庫的校對與本地化方面投入了極大心血：

  • 無縫對接的「肌肉記憶」：我們特別保留了港澳視障人士習慣的「點寫易」候選字排列順序！資深用戶完全不需重新適應，安裝完畢即可依靠原有的肌肉記憶迅速打字。
  • 清理歷史錯別字與深度本地化：針對舊字庫長期存在的錯字及繁簡混用問題，我們進行了大規模且精準的字元轉換，有系統地排除了大量歷史錯別字，確保輸出的每一句都符合標準繁體中文。
  • 納入香港口語及常用日文漢字：全面涵蓋「嘅、嘢、諗、啲、噉、𥄫、𨋢、擸、𡃁、埗、邨、駅」等日常用語、香港地名及港鐵站名，讓社群交流暢通無阻。
  • 契合香港習慣的點字編碼：針對部分特殊發音，我們微調了點字編碼對應，使其更加貼合香港本土的點寫邏輯。
  • 持續更新與優化：開發團隊承諾將不間斷地維護字庫。語言與時俱進，我們的字庫也會隨著香港人的用語習慣持續優化。

五、 三大模式自由切換 (Control + ` 快速切換)

系統內建三套專屬方案，只要隨時按下「Control + `」（數字 1 左邊的按鍵），就能自由切換：

  • 點心粵語點字 (記憶模式)：【預設推薦】具備智能學習特性，會自動記錄選字習慣與自訂新詞，將常用字往前排，越用越順手。
  • 點心粵語點字 (標準模式)：關閉記憶功能，候選字排列順序絕對固定。適合用於嚴格的測試與字庫校對，完全依賴傳統盲打記憶。
  • 點心粵語點字 (一陽指模式)：專為不熟悉「六點並擊」的用戶量身打造。只需用單根手指依序按下鍵盤字母來組合點字碼，重溫傳統鍵盤逐鍵輸入的體驗。

六、 給「點寫易」老用戶的溫馨提示

  • 整串字變成英文代碼（空碼）怎麼處理？
    如果因為打錯字或多按了標點導致畫面顯示一連串英文代碼，「千萬不要整串刪除」！只要按一下 Backspace (退格鍵) 刪掉最後一個出錯的符號，前方正確的中文字就會立刻恢復顯示。
  • 怎麼把連在一起的錯字拆開？
    如果系統自動組詞錯誤，可以按 Backspace 刪除後方字元並先輸出前面的字；或者手動在兩個字的代碼之間插入一個單引號 (')，系統便會強制將它們分開。
  • 關於英文字母 G 與 H 的輸出限制：
    由於系統翻頁快捷鍵的保護機制，在 Caps Lock 關閉且處於中文模式下，若按下 Enter 輸出點字鍵盤打出的英文原始碼時，g 與 h 必然會強制以大寫 G 與 H 顯示。

七、 跟傳統「點寫易」有什麼不同？

  • 完美相容最新環境：點心輸入法能夠在 Windows 10/11 及最新版本的 NVDA 上完美運行，確保再也不會遇到無法安裝的困擾。
  • 支援「長句連打」：點心具備強大的「自動組句」能力，您可以一口氣輸入一長串的點字編碼，系統會自動為您挑選最合理的詞語組合。
  • 極高自由度的客製化體驗：點心輸入法的設定檔為純文字格式，任何用戶都能輕鬆打開字典檔新增專屬的詞彙，不再受限於官方的更新進度。
